# Lay's Gold Standard — Asset Manifest

INTERNAL. Governs which visuals may be used on the Lay's Gold Standard pages.
**No random web images are imported into the CMS.** Only assets with acceptable
rights/editorial status enter Media; press thumbnails are Media relationships, never
hotlinks. If rights are unclear, the asset is **held for review** and not used
publicly. Historical campaign visuals are never fabricated.

Columns: Asset · Campaign · Source · Original URL/file · Owner · Rights confidence ·
Publicly usable? · Embed only? · Needs permission? · Preferred page use.

## Status for this phase
All Gold Standard Drafts were imported **without** binding any new campaign imagery.
Hero/section media are intentionally left empty pending a rights-cleared asset pass.
This is deliberate: it is better to ship Drafts with no image than to import
rights-unclear campaign visuals.

## Rules
- Prefer existing approved/static `/public/assets/**` where a suitable asset exists.
- Third-party brand/creator imagery requires explicit permission before public use.
- Geek's own report visuals may be usable but must have confidential figures/PII
  removed and scope labels applied before publication.
- Media security is unchanged (SVG remains rejected per policy; MIME restrictions intact).
