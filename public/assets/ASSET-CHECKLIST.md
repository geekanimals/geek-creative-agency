# Geek Homepage — Asset Checklist

Every visual slot on the homepage is wired to an exact file path. Drop the real
file at the path below and it renders automatically (no code change needed for
`<Media src>` items — set the `src`/`image` field in the matching `lib/data/*`
entry, or for one-off slots just place the file at the `need` path and point the
data at it).

**Rule:** no fabricated campaign visuals. A missing file shows a labelled slot
displaying its own required path.
